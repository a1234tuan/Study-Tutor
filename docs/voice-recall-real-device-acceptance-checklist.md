# 语音复述真机验收清单（Phase 6 / Gate 3）

> 自动化部分（schema 21、云白名单、备份恢复、no-op 同步、导出隐私、成本门控纯函数）已在 Vitest 跑过。
> 以下为依赖真实硬件/网络/Provider 的项，由用户在真机验收。凡未通过的项请反馈，不阻塞代码合入。

## 环境前置
- [ ] DeepSeek LLM 凭据已配置（ASR/TTS 真接入前仍为 Mock；本清单中标注 `[需 ASR/TTS 凭据]` 的项需要先提供凭据）。
- [ ] 设备：Android（Capacitor）+ 桌面（Electron）至少各一台。
- [ ] 麦克风/扬声器权限已授予。

## 音频与回声消除 [需 ASR/TTS 凭据]
- [ ] 安卓免提回声消除：扬声器播放时 ASR 不被自激（`systemCaptureGate` 应在 TTS 期间 gating）。
- [ ] 蓝牙耳机：连接/断开/切换时采集不中断或优雅降级；不残留旧设备路由。
- [ ] 有线耳机：插拔即时切换，无啸叫。
- [ ] 来电中断：通话中来电→暂停采集→挂断后能从暂停态恢复或干净结束（不串话）。

## 网络与后台 [需 ASR/TTS 凭据]
- [ ] 弱网/丢包：流式 SSE 断流→熔断/重连→恢复后续轮次；不出现半截回答。
- [ ] 后台切换：App 进后台→采集/播放暂停（卸载≠结束，检查点保留）→回前台恢复。
- [ ] 长会话：连续 ≥20min，达软上限（20min）请求门控生效（不再开新轮次，当前轮播完）。
- [ ] 配额用尽：Provider 返回配额/计费错误→经 `uiError.ts` 归一化展示诊断码，不泄露原始响应或密钥。

## 成本门控（§16）
- [ ] 80% 用量提醒 Toast 触发一次（默认 8min）。
- [ ] 软上限 20min 生效：达上限不再开新轮次。
- [ ] 结束页本机估算标注"仅供参考，以 Provider 账单为准"可见。

## 三类会话落地
- [ ] 自由主题：起始页可建、本地历史保留、结束三选一（不保留/保留本机历史/整理为日志）。
- [ ] 资料范围：AiKnowledgeScopePicker 选 ≥1 条、OCR 警告、上下文预算生效。
- [ ] 任务绑定：从 Coach 任务进入、`answerInputMode` 透传、一题一正式回答（提交后不可覆盖，追问建新 turn）。

## 隐私与同步
- [ ] 云同步：本机会话/轮次/历史不进入云实体映射（`voice-recall-*` 不在 `CloudSyncEntityType`）。
- [ ] 云拉取：不碰三类 local-only store（用户本机通话态与历史完整保留）。
- [ ] 完整备份恢复：临时会话/轮次被清除，本机通话历史保留。
- [ ] 导出：导出包不含原始音频/ASR partial/Provider 原始响应/密钥。
